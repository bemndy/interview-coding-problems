# Python coursework (ex21–ex36)

University DSA course, second half of the term. **Largely instructor-authored** —
see [`../../docs/ATTRIBUTION.md`](../../docs/ATTRIBUTION.md).

| Range | Topic |
|---|---|
| ex21–ex24 | Python types, debugging, unittest, parsing |
| ex25 | linked lists |
| ex26–ex28 | BSTs, tree search, AVL trees |
| ex29–ex30 | generators, `heapq` |
| ex31–ex32 | graph representation, BFS/DFS |
| ex33–ex35 | Dijkstra, Prim's MST, Kahn's topological sort |
| ex36 | dynamic programming |

Most exercises have `template/` (instructor scaffold) and `complete/`
(reference solution).
