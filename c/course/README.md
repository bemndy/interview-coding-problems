# C coursework (ex01–ex20)

University DSA course, first half of the term. **Largely instructor-authored** —
see [`../../docs/ATTRIBUTION.md`](../../docs/ATTRIBUTION.md).

Exercises are numbered in the order they were taught, roughly:

| Range | Topic |
|---|---|
| ex01–ex05 | C basics, debugging, pointers |
| ex06–ex09 | allocation, strings, structs, dynamic arrays |
| ex10–ex14 | stacks, tokenizing, search, recursion |
| ex15–ex16 | O(n²) and O(n log n) sorting |
| ex17–ex18 | linked lists |
| ex19–ex20 | hash tables: chaining and hash functions |

Most exercises have `template/` (instructor scaffold) and `complete/`
(reference solution).
